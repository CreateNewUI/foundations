# New UI Effects

## Install

Install New UI Effects from your terminal with npm:

```
npm i @new-ui/effects
```

You can also load the minified build from a CDN in your HTML `<head>`:

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@new-ui/effects@latest/dist/index.min.css"
/>
```

## Usage

Import the compiled CSS in a React app or bundler:

```js
import '@new-ui/effects/css';
```

For SCSS projects, load the package with `@use`:

```scss
@use '@new-ui/effects/scss';
```
